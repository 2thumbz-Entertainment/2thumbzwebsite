# 2ThumbZ Website

The official website for 2ThumbZ - the leading licensor of officially licensed collegiate content for digital publishing.

## Overview

This is a static HTML/CSS website designed to generate B2B inbound leads from:
- Mobile app developers
- Game studios
- Digital fashion/metaverse companies
- Media and entertainment companies

## Pages

- **Homepage** (`index.html`) - Main landing page with value proposition and lead capture
- **Content Catalog** (`pages/catalog.html`) - Browse available collegiate content
- **For Developers** (`pages/developers.html`) - Solutions for app and game developers
- **For Universities** (`pages/universities.html`) - Partnership information for schools
- **About** (`pages/about.html`) - Company history and mission
- **Contact** (`pages/contact.html`) - Contact form and information

## Technology

- Pure HTML5, CSS3, and vanilla JavaScript
- No build process required
- Responsive design for mobile, tablet, and desktop
- CSS custom properties for easy theming

## Color Palette

Based on the 2ThumbZ logo:
- Primary Blue: `#5DADE2`
- Dark Blue: `#2E86AB`
- Black: `#1A1A1A`

## Deployment

This site is deployed on Netlify. Any push to the main branch will trigger a new deployment.

## Local Development

Simply open `index.html` in a web browser, or use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```
